# Adant Create Ad

Before work, follow the [authentication preflight](../adant/references/authentication.md).

Follow the [durable project procedure](../adant/references/projects.md).
Select `agentKey: "adant-social-video"` with `adant_agent_start` after checking capabilities.

Create a complete ad using `product_ugc`, `template`, `avatar_video` or `custom`,
according to the brief and available capabilities. Ground product, avatar and
template ids in owner-visible library reads. Include audience, platform, duration,
aspect ratio, offer, language and acceptance criteria. Ask only for missing
inputs that materially change production. AdAnt owns planning, generation,
refinement and artifacts. Never approximate a complete ad with disconnected
primitive generations.
