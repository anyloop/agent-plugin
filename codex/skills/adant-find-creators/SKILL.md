# Adant Find Creators

Before work, follow the [authentication preflight](../adant/references/authentication.md).

Follow the [durable project procedure](../adant/references/projects.md).
Select `agentKey: "adant-creator-scout"` with `adant_agent_start` after checking capabilities.

Use `projectType: "creator_discovery"`. Include product/category or source
strategy, requested platforms, count and the user's hard filters. Ask for a saved
creator shortlist with profile and authored-content evidence, measured metrics,
product fit and collaboration ideas. Do not invent location, language, identity,
availability or contact information. A shortage remains a shortage; never
loosen the user's filters or contact creators without instruction.

If the user wants human video editors, say that creator evidence does not prove
editing services or hiring availability. Include that distinction in the brief
and request only supported public evidence; do not advertise a dedicated editor
marketplace. For editing an actual video use `adant-video-editor`.
